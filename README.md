## 🚀 Shipped

### 🔦 [Highlight Bar](https://apps.apple.com/us/app/highlight-bar/id6784490882) — *live on the Mac App Store*

A macOS reading guide that stays above other apps. A soft bar follows the cursor to help readers keep their place; spotlight mode dims surrounding content; and screen tint adds warmth without distorting colors.

Designed as an accessibility tool for readers with dyslexia, ADHD, low vision, or visual stress (Irlen).

**Native on macOS and Windows.** The open-source release provides the same feature set in a Swift menu-bar app and a C# WinForms tray app: a click-through overlay, multi-monitor cursor tracking, customizable bar dimensions, keyboard shortcuts, and system-level hotkeys.

Preparing the macOS app for App Store release involved sandbox entitlements for global hotkeys, click-through overlay windows, conditional compilation for App Store and direct releases, and packaging native code as a relocatable bundle.

Runs entirely on-device — no account, no data collection, no special permissions. MIT licensed.

`Swift` `SwiftUI` `C#` `WinForms` `macOS system APIs` `App Sandbox` `GitHub Actions` `Accessibility`

[📱 App Store](https://apps.apple.com/us/app/highlight-bar/id6784490882) · [💻 Source](https://github.com/25mattm/Highlighter)
